# שיטות כמותיות בניהול

אתר הקורס: https://shaytsaban.github.io/quantitative-methods-in-management/

המרכז האקדמי למשפט ולעסקים, רמת גן. מרצה: ד״ר שי צבאן. 13 מפגשים, ציון: בחינה מסכמת 100%.

קרדיט לתכנים עצמם וליצירת תוכן הקורס: ד״ר אסף שריג. קרדיט לעיצוב הפדגוגי, ההמחשות, הדוגמאות, בניית המצגת ותהליך הלמידה: ד״ר שי צבאן.

- `index.html`: דף הבית, עם תוכנית 13 המפגשים.
- `lectures/lecture-1/`: מצגת מפגש 1 (`presentation.html`) וסיכום PDF (`summary.pdf`): ריענון באלגברה ומיומנויות אלגבריות.
- `materials/`: סילבוס, חוברת תרגילים (`booklet.pdf`) ופתרונות מלאים (`booklet-solutions.pdf`).
- `_build/`: מקורות הבנייה. התוכן כתוב פעם אחת (`content_l1*.py`) ומזין גם את המצגת וגם את הסיכום.
  - המתמטיקה נכתבת בתחביר פשוט (`8x^2-6x-5`), מוצגת ב-HTML (`qlib.PM`), ונבדקת מספרית בזמן הבנייה (`qlib.chain`): כל שורת פתרון חייבת להיות שווה לתשובה.
  - `python3 build_deck.py 1`: המצגת. הפעילויות (תשובה מוקלדת שנבדקת כביטוי, רמזים, פתרון בשלבים) רצות על `act.js`.
  - `python3 test_deck.py`: בדיקה בדפדפן ללא ממשק: שקפים שחורגים, כיוון כל ביטוי מתמטי (משמאל לימין, תו אחר תו), וכל פעילות: דוחה תשובה שגויה ומקבלת תשובה נכונה.
  - `python3 shots.py <תיקייה>`: צילום של כל שקף, לבדיקה בעין.
  - `python3 build_summary.py 1`, `python3 build_booklet.py`, `python3 build_syllabus.py`, `python3 build_hub.py`.
